## Sobre mim

Sou Gabriel Costa, desenvolvedor web e estudante de Análise e Desenvolvimento de Sistemas no Rio de Janeiro. Gosto de entender o caminho inteiro de uma funcionalidade: da interface ao banco de dados. A **LuiZa** e o **CariocaStore** são dois jeitos diferentes de colocar isso em prática.

Hoje, meu foco de estudo está em **SQL, Docker e desenvolvimento de APIs e Cloud**.
